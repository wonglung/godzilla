# 出國行程與費用試算

從台灣出發的國外旅遊網站：選目的地（可複選）、天數、預算等級、季節與人數，就會列出每日建議行程與大約費用，並把多個目的地依每人費用排序比較。純靜態網頁，不需要建置。

## 功能

- 11 個目的地：東京、大阪京都、首爾、曼谷、峴港會安、新加坡、巴黎、羅馬佛羅倫斯、倫敦、紐約、雪梨；可依地區快速選取
- 天數 3～14 天；預算等級（經濟／標準／豪華）；季節（淡季／一般／旺季）；人數
- 費用明細：機票、住宿、餐飲、交通、門票活動、保險網路與簽證；顯示每人、全團與每人每天
- 每日行程：第 1 天抵達、最後一天返台，中間依景點排入；天數超過景點數時補上自由活動
- 選填每人預算上限，會標示「超出預算」與建議；天數低於建議天數會提醒

## 修改資料

所有價格與行程都在 `data.js`。`cost` 裡每個欄位的三個數字依序是經濟、標準、豪華，單位新台幣、每人計算：`flight` 來回機票、`hotel` 每晚（兩人一房均分）、`food`／`transport`／`activity` 每天、`fixed` 簽證等一次性費用。`plan` 是每日行程，依順序排入。

計算方式在 `app.js` 的 `estimate()`：季節係數只套用在機票與住宿；一人旅行住宿以 1.7 倍計（單人房）；金額四捨五入到百位。

## 預覽與驗證

直接用瀏覽器開啟 `travel/index.html`，或在儲存庫根目錄執行 `python -m http.server 8000` 後開啟 http://localhost:8000/travel/ 。

- 語法檢查：`node --check travel/app.js`、`node --check travel/data.js`
- 畫面：[手機](../docs/travel-mobile.png)、[桌面](../docs/travel-desktop.png)

金額為估算值，實際價格依匯率、航空公司、訂房時間變動；簽證規定請於出發前確認。
