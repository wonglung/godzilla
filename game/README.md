# 時間守護大作戰

「一二三木頭人」小遊戲，可選角色為小新、小白、小葵。純靜態網頁，不需要建置。角色圖示使用 emoji，不使用任何官方圖片。

## 玩法

- 選擇角色：
  - 👦 小新：速度普通，技能「屁屁舞」讓黑時計笑到 3 秒內不回頭。
  - 🐶 小白：速度最快，技能「棉花糖」縮成一團，2.5 秒內被看到也不會被抓。
  - 👶 小葵：爬得較慢、多一顆愛心，技能「閃亮亮眼神」擋下一次被抓。
- 黑時計背對你時按住「按住前進」；出現「滴答滴答」就要放開；被他盯著時還在動就會被抓（扣一顆愛心並後退）。
- 共三關：村子廣場、竹林小路、時計城。越後面回頭越快，第二、三關還有假動作。
- 在月亮升到最高點（時間限制）前抵達沙漏就過關。分數＝剩餘秒數 × 10 ＋ 愛心 × 50，最高分存在本機瀏覽器。
- 鍵盤：按住空白鍵或 → 前進，E 使用技能。

## 預覽與驗證

直接用瀏覽器開啟 `game/index.html`，或在儲存庫根目錄執行 `python -m http.server 8000` 後開啟 http://localhost:8000/game/ 。

- 語法檢查：`node --check game/game.js`
